## Descripción

Este repositorio contiene la resolución de la Tarea Práctica de la Unidad III correspondiente a la materia Taller de Programación de 5.ª Generación I.

### Ejercicio 1

En este ejercicio se realizó una composición gráfica utilizando el algoritmo DDA. Se dibujó una casa formada por líneas, incluyendo el cuerpo de la casa osea las paredes, techo, puerta, ventanas, piso y sol. Además, se agregaron algunos elementos decorativos como nubes y flores para complementar la composición. El objetivo fue aplicar el algoritmo DDA para construir distintas figuras a partir de líneas simples, comprender el funcionamiento de cada función implementada y ver como se pueden crear composiciones gráficas más complejas mediante la combinación de elementos básicos.

### Ejercicio 2

En este ejercicio se realizo una composición gráfica utilizando el algoritmo de Bresenham. Para ello se generaron puntos distribuidos sobre una circunferencia y posteriormente se conectaron entre sí mediante líneas, formando diferentes patrones geométricos llamados rosetas. Se generaron tres variantes (3 imagenes) utilizando 12, 24 y 36 puntos, aplicando distintos colores a las líneas para obtener un efecto visual más llamativo. El objetivo fue poner en práctica el algoritmo de Bresenham, comprender cómo se generan puntos sobre una circunferencia mediante funciones matemáticas y observar cómo la conexión de estos puntos permite crear composiciones gráficas cada vez más complejas.
